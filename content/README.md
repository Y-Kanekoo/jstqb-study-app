# 問題コンテンツ領域

公開リポジトリには、UIと検証を動かす少数の独自サンプルだけを`src/content/questions.ts`へ収録します。本番500題はライセンス、転載防止、レビュー履歴保護のためSupabaseの非公開データとして管理します。

## 本番投入条件

- 配分: 1章100、2章75、3章50、4章138、5章112、6章25
- Kレベル: K1 100、K2 300、K3 100
- schema検査、重複検査、技術レビュー、表記レビュー、画面プレビューを通過
- 作成者と技術レビュー担当を分離
- 本人による最終承認
- `published`だけを有効問題数へ算入

AI生成や下書きは問題数へ含めません。公開済み問題は直接更新せず、新しい問題版を作成します。
