# 実機受入チェックリスト

リリース候補ごとに、iOS、Android、Safari、Chromeで実施します。実施者、端末、OS、アプリ版、日時、結果をリリース記録へ残します。

## 保存・復元

- [ ] 選択直後にアプリを強制終了し、未確定の選択が戻る
- [ ] 回答確定直後に終了し、回答履歴が1件だけ増える
- [ ] 次問表示直後に終了し、同じ現在位置へ戻る
- [ ] 通常演習と誤答演習を中断し、両方がホームに残る
- [ ] Webで選んだ未確定回答をモバイルで再開できる
- [ ] オフラインで回答後、再接続で欠損・重複なく同期する
- [ ] server発行済みoffline practice packを10/20/30/40問で開始でき、正答・解説を事前取得せず、kill/restart後も現在位置と未送信回答が戻る
- [ ] packなし、別account、別generation、期限切れ、consume済みbasisではoffline新規開始できない
- [ ] 端末容量不足時に次問へ進まず「保存できません」を表示する

## 誤答・模試

- [ ] 誤答後に未克服へ入る
- [ ] 過去すべて、期間内、直近、克服済みを切り替えられる
- [ ] 別セッション2回連続正解で克服し、再誤答で未克服へ戻る
- [ ] 模試中に正答・解説が表示されない
- [ ] 模試を閉じても60分の壁時計タイマーが止まらない
- [ ] 停止問題が採点分母から除外され、分母40未満では合否なし・参考得点になる
- [ ] offline参考模試は保存済み全ordinalを欠番・重複なく専用結果へ表示し、停止/revoke項目は本文・選択肢・正答・解説なしtombstoneへ置換して、正式履歴・誤答・SRSを変えない

## アクセシビリティ・表示

- [ ] VoiceOverまたはTalkBackで問題から解説まで完了できる
- [ ] 選択状態、正誤、保存状態を色なしでも判別できる
- [ ] OS文字サイズ200%で回答・確定・次問操作が欠けない
- [ ] 320px相当の幅で横スクロールが発生しない
- [ ] 外付けキーボードだけで主要操作を完了できる
- [ ] 動きを減らす設定で不要なアニメーションが停止する
- [ ] 前問の解説が背景到着しても、現在操作中の問題・modal・screen readerのfocusを奪わない
- [ ] スマホは1列＋下部navigation、desktopは左navigationとなり、状態・ラベル・操作結果が同一である
- [ ] tablet/desktopの補助paneは学習上必要な場合だけ表示され、未回答時に正答・解説を先読みしない
- [ ] 320px、スマホ横向き、tablet、desktopの各幅で回答操作・保存状態・問題報告が欠けない
